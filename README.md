<h3>⚡ TurboQuant × ViT</h3>
<p>I ported TurboQuant KV-cache compression (ICLR 2026, <a href="https://arxiv.org/abs/2504.19874">arXiv:2504.19874</a>) to ViT-B/16 and benchmarked it on CIFAR-10 (256 test images). At 3 bits it gives <strong>9.14× KV-cache compression</strong> and saves <strong>85.9% of memory</strong> with no top-1 loss (83.98%). PolarQuant at 3 bits reaches 10.67×, and TurboQuant at 2 bits reaches 12.80× at −1.17% top-1. A Triton kernel is planned, not built yet.</p>
